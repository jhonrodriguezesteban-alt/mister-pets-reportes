# Mister Pets — página web mayorista

Sitio informativo para clientes mayoristas (pet shops, veterinarias, locales de mascotas).
Next.js + Tailwind CSS. Ver `BRIEF.md` para el brief y los pendientes.

```bash
npm install
npm run dev   # http://localhost:3000
```

- Textos y datos: `src/content.ts`
- Página: `src/app/page.tsx`
- Fotos (provisionales): `public/images/`
